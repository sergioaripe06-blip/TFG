1. Objetivo de este documento

Este manual de uso explica la aplicación de forma sencilla, pensando en una persona que no conoce el proyecto de antemano.

Su función es ayudar a entender qué hace cada pantalla, qué opciones tiene el usuario y dónde conviene insertar capturas para apoyar la explicación.

2. Cómo usar este manual

Lo más recomendable es leerlo siguiendo el flujo natural de uso de la app: acceso, pisos, espacio interno del piso, balance, calendario, perfil y ajustes.

Cada apartado incluye una explicación clara, una lista de acciones del usuario y un hueco preparado para colocar la captura correspondiente.

5. Vista general de la aplicación

Una vez dentro, la navegación principal se organiza desde la barra inferior. Las pestañas más importantes son Pisos, Balance, Calendario y Perfil.

Cada una cumple una función concreta y permite separar la parte económica, la parte organizativa y la información personal del usuario.

6. Pestaña Pisos

Esta pantalla reúne todos los pisos a los que pertenece el usuario.

Desde aquí se puede crear un piso, unirse a uno existente y entrar al espacio de trabajo de cada vivienda.

Figura 4. Pestaña Pisos con los pisos disponibles del usuario. Insertar aquí la captura de la pestaña Pisos.

6.1 Detalle de un piso

Al pulsar sobre un piso se puede acceder a su detalle o directamente a su espacio interno. En esta parte conviene enseñar el nombre del piso, sus miembros y las acciones principales disponibles.

7. Dentro de un piso

Cuando se entra en un piso, la aplicación cambia a un espacio interno con varias subpestañas propias. Las más relevantes son Movimientos, Recordatorios y Gestión.

8. Subpestaña Movimientos

Es la zona económica principal del piso. Aquí se gestionan gastos, estados, justificantes, vencimientos y reparto entre personas.

En la parte superior aparecen filtros rápidos por estado y el botón Filtros. Debajo se muestran las tarjetas de movimientos.

En las tarjetas conviene explicar los campos Solicitado por, Para, Fecha del gasto, Día límite, importe y estado.

Figura 6. Pantalla Movimientos con filtros rápidos y listado de gastos. Insertar aquí la captura de la subpestaña Movimientos.

8.1 Crear un gasto

Desde esta parte se abre el diálogo Nuevo gasto, que permite registrar concepto, importe, categoría, prioridad, fecha límite, reparto y ticket.

Es importante explicar que el ticket es obligatorio y que la persona pagadora no aparece como destinataria en el reparto por personas.

Esta sección se usa para organizar tareas, avisos y acciones repetitivas dentro del piso.

Conviene mostrar una captura donde se vea la lista de recordatorios, la información básica de cada uno y la acción para crear un nuevo aviso.

10. Subpestaña Gestión

En esta parte se concentran herramientas de organización interna del piso, como incidencias, reglas y horarios.

Es buena idea explicar cada bloque por separado para que se entienda que no todo en la aplicación es dinero: también hay convivencia y seguimiento del día a día.

15. Consejos para preparar capturas

  • Usar datos de ejemplo claros y fáciles de entender.
  • Evitar correos o teléfonos reales si el documento se comparte.
  • Capturar pantallas con contenido representativo y bien visible.
  • Mantener siempre el mismo tamaño o proporción cuando sea posible.
